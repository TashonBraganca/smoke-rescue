Smoke Rescue simulates two rescue robots searching a burning building in Unity on a Mac. Each robot uses its own RGB-D, thermal and IMU sensors, a reflex brain, and an LLM agent that calls OpenCV 5 tools before issuing evidence-backed orders. A commander coordinates the search over a lossy radio, while recorded traces and offline evaluation let you inspect what happened.

03 / Offline evaluation

With and without agents

Choose a run to load metrics.

Values come from brain.compare_runs. Agent counters come from the run summary and can differ from the executed calls in the trace. Search area is a coverage proxy within 2.5 m of the true paths, sampled on a 0.5 m grid. It is not verified visible floor area. A survivor match uses a 1.5 m threshold. Compare duration and scenario before drawing conclusions; a short test does not establish a rescue benefit.
