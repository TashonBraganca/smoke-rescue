Two robot dogs. One burning house. No map.

Search through smoke.
Inspect every decision.

Smoke Rescue sends two quadruped robots into a burning house they have never seen. Each robot runs the same onboard brain: it explores room by room, finds people with OpenCV 5 colour and thermal detection, and builds a map it shares with its partner over a lossy radio. OpenCV 5 ORB place recognition corrects the shared map when one robot sees a place the other already mapped. Terra, a GPT-5.6 agent, reads each robot's report a few times per mission and suggests the next room to search; the brain checks every suggestion and keeps moving while Terra thinks. When the search is done, both robots walk out along their own trail.

On 39 real floor plans the brain had never seen (HouseExpo, headless simulator, 25 October 2026), two robots sharing one map found 99% of people and one robot found 92% (p = 0.002). Map merging measured robot B's start tilt as 2.42 degrees against a true 2.39 degrees, with no duplicated people.

Live missions on AWS last 180 simulated seconds, run at most two at a time, and allow Terra up to 20 decisions each. If AWS cannot start a run, the website plays a checked recording of the same setup and says so.
